# Retired job flags

Beginner welcome and instant repeat approval are retained here for history, not imported by the active app. The database fields and form/row codec remain round-trip compatible: hiding a feature must not reset stored values. These modules must not be wired back into the app without a separate review of the server-side isolation migration.

The active experience preference remains available. The former repeat_approval URL and saved page ID explicitly resolve to worker_preferences; legacy numeric steps are unchanged.
