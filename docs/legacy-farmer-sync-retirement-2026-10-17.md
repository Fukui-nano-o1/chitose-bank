# 旧 farmer 同期APIの廃止（監査 A00）

確認日: 2026-10-17。対象: `api/sync-farmer.js`。
基点: main `aa2abb0465e519b567c08f1758a3f751e86d09a5`。
発見元: [入力保存経路の監査 PR #11](https://github.com/Fukui-nano-o1/chitose-bank/pull/11)。

## 問題と対応

旧APIは認証を確認せず、リクエストのメールアドレスを使って `farmers` を管理者権限で upsert していた。本人以外の行を書き換える経路になるため、最優先で閉鎖する。

現行の `src` に `sync-farmer` の呼び出しは見つからなかった。APIを廃止し、全メソッドで HTTP 410 と `Cache-Control: no-store` を返す。HEAD は本文なし、それ以外は固定の `LEGACY_ENDPOINT_RETIRED` を返す。旧クライアントへの廃止応答を明示するため、ルート自体は残す。

管理者キー、Supabaseクライアント、DB照会・更新、監査ログ書き込みをこのAPIから削除した。リクエスト本文と認証情報は参照しない。正常終了を装う応答や、別の書き込み先への転送は行わない。

## 検証

`scripts/legacy-sync-retirement.test.mjs` を `test:critical` と専用の GitHub Actions に組み込んだ。

| 検証 | 結果 |
| --- | --- |
| 修正前のコードへ追加テストを実行 | 7件失敗。環境変数への依存と、匿名を含むPOSTから外部通信を試みることを検出。通信は全件遮断した |
| 修正後の同じテスト | 7件成功、外部通信0回 |
| 環境変数なしでの import | 成功 |
| 匿名・無効トークン・旧クライアント相当のPOST | 全て410、入力値の応答への混入なし |
| GET / HEAD / PUT / PATCH / DELETE / OPTIONS / POST | 全て410。例外を投げる本文・ヘッダーのgetterも参照しない |
| `TZ=Asia/Tokyo npm run build` | 290件成功、失敗・スキップ0件。本番用バンドル生成成功。Lintエラー0件、変更していない既存部分の警告19件 |
| 構文・差分検査 | `node --check`（APIと追加テスト）、`git diff --check` 成功 |

テストはダミー値のみを使用し、本番DBへの書き込みは行っていない。リポジトリ外の旧クライアントの利用有無は確認できないが、利用していても今後は410となる。

## 反映時の確認

この修正は main を基点とする独立した変更であり、PR #7〜#11 の未反映変更やDBマイグレーションを必要としない。既存の画面・ログイン処理・テーブル定義は変更していない。

実装・ローカル検証の完了と、本番閉鎖の完了は別に記録する。本番反映後にデプロイのコミットを照合し、`HEAD /api/sync-farmer` が410かつ `Cache-Control: no-store` となることを確認する。それまでは本番の問題を解消済みと扱わない。

切り戻しでも旧サービスロール書き込みを復活させない。将来同期が必要になった場合は、検証済みの本人IDと必要最小限の権限を持つ別の経路として設計する。
