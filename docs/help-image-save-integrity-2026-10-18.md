# ヘルプ画像の保存（A12）

対象は使い方ガイドとインストール案内の画像追加・差し替え・削除・一括軽量化。

`src/lib/helpImageRecord.js` が読込状態、本人確認、新規ファイルの確認、DB参照の比較保存を管理する。画面は確定行だけを反映する。DBの窓口は `save_help_image_reference`。固定search_pathのinvoker関数で、本人IDと管理者所属を確認し、既存RLSを維持する。

ファイルは `help-images/v2/{slot}/{uuid}.{ext}` の一意なパスへ、上書き禁止でアップロードする。応答紛失時は同じパスの内容をバイト単位で照合する。以前のファイルが存在することだけでは成功にしない。

DBの参照は表示時のURLと更新日時を比較して変更する。競合、0件更新、0件削除は成功扱いしない。DB応答を失った場合は正本の参照を読み直す。結果不明なら画面を完了へ進めない。

削除操作はガイドのDB参照だけを外す。差し替え・削除・軽量化の処理からStorageファイルの削除を廃止した。他のスロット、古い画面、進行中の通信がURLを保持していても、画像本体を壊さない。未参照ファイルの物理清掃は別途、参照と保持期間を確認して行う必要がある。今回は清掃を実行せず、保存容量の削減を保証しない。一括軽量化の削減表示は配信する画像のサイズ差。

初期読込に失敗した場合は未登録と区別し、書込操作を止めて再読込を表示する。追加・削除・軽量化は同時に開始できない。一括軽量化は確認済み件数と未確認件数を区別する。

検証は本番の列・主キー・RLS述語に対応した実SQL、保存管理コード、実React画面。アップロード拒否、DB拒否、応答紛失、読み戻し失敗、競合、0件更新、別人、二重開始、軽量化中の削除を含む。本番画像の変更・削除試験は実施しない。旧クライアントは再読込が必要。
