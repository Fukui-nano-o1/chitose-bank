# 通報・サポート 対応手順書

更新日：2026-09-23

管理画面の「通報・サポート」から開きます。画面右上の「対応手順」にも同じ流れの案内があります。

## 基本の流れ

1. 「要対応」から案件を開き、種類・対象・受付日・本文を確認します。
2. 案件内の「次にすること」と「この案件の対応手順」に沿って、対象や記録を確認します。
3. 必要に応じて運営チャットで事実を確認し、修正依頼などの対応を行います。
4. 確認と必要な対応を終えてから「対応を完了する」または「確認結果を記録する」を選びます。確認画面で結果を保存すると「対応履歴」に移ります。

確認を続ける場合は、完了せず一覧へ戻ってください。案件を開いたり手順書を読んだりしても、状態は変わりません。

## 状態の意味

| 状態 | 意味 | 次の操作 |
| --- | --- | --- |
| 未対応 | 確認・対応が必要 | 内容と対象を確認 |
| 事実確認中 | 未払いの申告について確認を開始した | 双方への確認を進める |
| 対応済み | 未払い以外の案件の対応を終了した | 対応履歴から内容を閲覧 |
| 解決済み | 未払いの問題の解消を確認して終了した | 対応履歴から内容を閲覧 |
| 未解決で終了 | 未払いの解消を確認できないまま対応を終了した | 解決済みと区別して履歴を閲覧 |
| 表示サンプル | 本文などの先頭に「【デモ】」の記載がある | 一覧下のサンプル欄で閲覧 |

## 種類別の確認

| 種類 | 確認する内容 | 対応の進め方 |
| --- | --- | --- |
| 未払い | 「申告時の記録」の契約の報酬・日程・支払時期、日次の記録、最終回答 | 「事実確認を始める」で状態を記録。働き手と雇い手それぞれに支払日・金額・受け取り状況を確認。結果を選んで保存 |
| 求人 | 「対象の求人を確認」から指摘された項目と掲載内容を照合 | 不明点を通報者に確認。修正が必要なら求人の確認画面から依頼。対応を終えてから完了 |
| コメント | 通報時に保存されたコメント本文と補足 | 必要に応じて通報者・発言者それぞれに前後の事情を確認。必要な対応を終えてから完了 |
| プロフィール | 指摘されたプロフィール、または「はたらいた記録」の項目 | 必要に応じて本人と通報者に事実確認。必要な対応を終えてから完了 |
| 画面・機能 | 本文・対象ページ・報告時の画面幅 | 操作を確認し、修正や案内。提案なら対応方針を整理。対応後の確認を終えてから完了 |

通報は利用者からの申告です。確認前に違反や未払いと決めつけず、通報者の情報を相手へ転送しないでください。

「運営チャット」は確認先を開きます。メッセージを入力して送信するまでは連絡されません。

## 完了操作で起こること

案件の状態を更新して対応履歴へ移します。この操作だけで求人やコメントの削除、アカウント停止、相手への通知は行われません。必要な実際の対応は、その前に行ってください。

未払いの申告時の記録は、保存時点の内容です。その後の支払い状況は当事者に確認してください。記録がない項目は推測せず、「記録なし」として表示します。

## 読み込めない・保存できないとき

- 取得エラー時は、取得できた内容と前回の内容が表示されます。件数は最新でない可能性があります。一覧の「再読み込み」を押してください。
- 最新の状態を取得できない種類の案件は更新できません。
- 保存に失敗した場合や別の操作と状態が競合した場合は、完了扱いにしません。一覧を再読み込みして、現在の状態を確認してください。
- デモ表記のある報告は削除せず別欄で表示し、要対応件数に含めません。サンプル欄から状態の更新や当事者への連絡はできません。
