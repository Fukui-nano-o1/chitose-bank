# 応募者詳細

応募者一覧の「応募詳細」「応募内容を確認」から開く。

- 上部に閉じるボタンを常設。人物、状態、対象求人を識別できる構成。
- 「プロフィール」には自己紹介・経験・資格・言語・趣味・働き方を整理。本人申告と連絡先確認の区別を維持。
- 「応募内容・日程」に求人への直接リンク、勤務日、契約成立後に許可された氏名・緊急連絡先を配置。
- 操作は下部1箇所。採用の最終確認、承認、見送り、保留、対応済み、記録、評価の既存処理を継続使用。
- 同じ操作の上下重複、6段の進捗バー、求人の中間プレビュー、質問の吹き出し表示を撤去。
- body直下のportal＋visualViewport追従。ヘッダーと操作欄をスクロール本文の外に置く。フォーカスを閉じるボタンに移し、閉じたら元のボタンに戻す。
- 日程は応募者一覧・カレンダーと同じworkDaysStripDataで導出し、希望日・合意日・求人期間・休日を一貫して扱う。

参考：Airbnb公式のゲスト情報の整理方針（https://www.airbnb.jp/help/article/3144）。情報の公開範囲はchitose-bankの既存仕様を維持し、追加の個人情報取得や採用判定は行わない。

検証：scripts/applicant-cards.test.mjsで実FarmerDashboardからの開閉、フォーカス復帰、タブ切替、操作の重複防止、320×460のvisualViewport追従、休日除外、求人への直接遷移を確認。
