# 応募確認の専用ページ（2026-10-02）

求人詳細とカレンダーの日程からの応募入口を、確認ボックスから専用ページへ変更。

- URL: `#/work/job/{番号}/apply/intro` → `about` → `dates` → `confirm`（最終確認は期間求人のみ）。
- 戻る操作は来た履歴を戻る。直リンクでは前の確認ページ／同じ求人詳細へ戻る。
- 期間求人では特定日または「期間中いつでもOK」を選んで最終確認。休日は候補から除外。
- 日程の選択は本人・求人別のsessionStorageに保持。戻る・再入場・再読み込みで復元する。
- 下部操作は常設。送信中は操作を無効化し、同期的な送信ロックで連打も防ぐ。
- 応募API、仮応募、本人登録・プロフィール判定、応募完了の行き先は既存処理を使用。
- 通信失敗時はページと選択を保持。募集終了・応募済み・本人の求人・未ログインは新規送信を拒否。

検証: `scripts/job-expiry-ui.test.mjs` で実際の検索コンポーネントをマウントし、ページ遷移・日程保持・休日除外・カレンダー入口・単日／期間／いつでもOKの送信payload・通信失敗後の再試行・募集終了時の拒否を確認。すべての通信はテスト用クライアントに閉じ、本番書き込みは行わない。
