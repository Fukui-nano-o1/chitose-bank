# 仕事の評価：良い点5分類・悪い点5分類

更新日：2026-09-29（日本時間）

働き手から農家への「仕事の評価」を、良い点5つ → 悪い点5つ → 送信前の確認に変更。
各ページで複数選択でき、該当しない項目は選ばず進める。
未選択で終了する場合も、確認画面で明記する。農家から働き手への評価は既存のまま。

| 分類 | 良い点のページ | 悪い点のページ | 保存先 |
| --- | --- | --- | --- |
| 仕事内容 | 求人の内容どおりだった | 求人の内容と違いがあった | `as_described` |
| 説明・教え方 | 説明・教え方が分かりやすかった | 説明・教え方が分かりにくかった | `instructions_clear` |
| 安全・休憩 | 安全や休憩への配慮があった | 安全や休憩への配慮が足りなかった | `safety_care` |
| 報酬 | 報酬が約束どおりだった | 報酬が約束どおりではなかった | `paid_as_posted` |
| 次回の仕事 | またこの農家で働きたい | また働きたいとは思わなかった | `want_again` |

## 入力と保存

- 同じ分類を良い点と悪い点の両方にはしない。反対側で選択すると後の回答へ切り替え、画面内で通知する。
- 戻る・確認から変更では回答を保持。別の応募・アカウントではページ位置も回答も初期化する。
- 良い点は `true`、悪い点は `false`、未選択・取り消しは `null`。未選択を否定として数えない。
- `match_level` は肯定のときだけ `matched`。悪い点から違いの程度（一部／大きい）を推測しない。
- `pay_status` は肯定なら `paid`、否定なら `other`。否定に加えて「まだ報酬を受け取っていない」を明示した場合だけ `unpaid` にする。
- 未払いの説明は選択時と送信前に表示。既存の未払い申告トリガーにつながる。報酬の回答を解除・肯定へ変更すると、未払いチェックも解除する。
- `want_again_choice` は肯定 `yes`、否定 `no`、未選択 `null`。
- 通信失敗は確認画面で知らせ、回答を維持して再送できる。連打を抑止し、保存済みなら再投稿せず元の仕事へ戻れる。

## 公開とスマホ表示

既存の `reviews_public_badges` が5項目の `is true` だけを集計する。
悪い点の原文・個々の評価者は相手に表示しない。
双方の評価が揃うか、仕事の完了から3日たつまで集計の公開を待つ条件も維持する。
以前の「時間どおりに開始」の肯定件数は履歴として残し、0件なら新しい評価項目に並べない。

全画面を `document.body` の直下に表示し、変形された親要素に閉じ込められないようにする。
見えている画面の大きさ（`visualViewport`）、セーフエリアに合わせ、見出し・戻る・閉じる・下部操作を本文スクロールから分離。
ページ移動時は見出しへフォーカスを移し、閉じると元の操作へ戻す。
