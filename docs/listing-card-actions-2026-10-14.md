# 掲載カードの操作仕様

確認日: 2026-10-14

通常のタップは下書きの再開・掲載済み求人の閲覧を維持します。450msの長押し、右上の操作ボタン、Shift+F10で1件を選択します。選択中は黒枠と選択中ラベルが付き、下部ナビの上の白いアクションバーに求人名・番号を表示します。

未掲載の下書きは再開・コピー・削除、公開中は編集・コピー・非公開、終了した掲載済み求人はコピーのみです。実行時にも現在の行と状態を確認し、対象番号を固定します。削除・非公開の確認にも求人番号を表示します。

外側のタップ・閉じる・Escape・タブ切替・画面遷移・対象の消失で選択を解除します。スクロールは阻害せず、10px超の移動で長押しを取り消します。通信中の重複操作は禁止し、エラー時は結果不明を明示します。

検証: `npm run build` と `node scripts/own-job-actions.browser.mjs`。ブラウザ試験は架空データだけを用い、外部通信を遮断しています。iPhone実機と本番の実求人を削除する試験は行っていません。並行反映された保存復旧の修正（c11b89a）を保持して統合し、保存処理と保存競合テストは最新mainをそのまま採用しています。
