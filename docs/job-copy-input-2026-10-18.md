# コピー時の入力保全（A16）

確認日: 2026-10-18。基点main: `c6f797ac232f5c566de108b1c0e1715f9bd436f7`。

現行の`copy_job`は新しい入力列を列挙しておらず、場所・作業の変更範囲と動画を失っていた。本番関数を読み取ったfixtureで欠落を再現した。

## 入力の扱い

| 項目 | コピー先 |
| --- | --- |
| 仕事内容・場所・報酬・待遇・写真・危険・位置情報・変更範囲 | 値を保持 |
| 作業日程・休日 | 既存方針どおり空にする |
| 動画URL | 非公開の下書きへ保持 |
| 動画の求人内掲載同意・関連掲載同意・時刻・文言版 | 新しい求人なので解除し、利用者が再確認する |
| 入力ページ | 確認ページの番号12と安定ID `review` を保存 |

44項目のコピー規則を`jobInputFields.js`の`JOB_COPY_POLICY`へ追加。DB試験で全項目を元行と照合し、新しい入力列を関数に追加し忘れた場合も検出する。満額支払条件は既存値を保持し、業務仕様を変更しない。

動画の同意文言は「この求人」の掲載許諾であるため、コピー元の同意を新しい同意として扱わない。URLを失わず下書きに置けるよう、DB制約には「draftかつ未同意・関連同意なし・時刻／文言版なし」の場合だけ例外を追加する。pending/open等に進むには従来どおり同意・時刻・文言版が必須。公開ビューは既存どおり同意済みURLだけを表示する。

確認画面から直接掲載する場合も、動画URLとこの求人への同意を検査し、不足時は作業動画の入力画面へ移動する。URLの再入力を要求しない。関連掲載は任意のまま。
