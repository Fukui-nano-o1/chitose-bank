# 労働条件通知書の専用ページ（2026-09-29）

応募者一覧、働き手の応募状況、予定詳細から、応募IDごとの専用URLへ移動する。

- 募集主：`#/profile/employer/notice/{applicationId}`
- 働き手：`#/profile/worker/notice/{applicationId}`

上部に戻る操作、下部に印刷とPDF保存を配置し、本文だけをスクロールする。元画面の履歴へ戻るため、予定詳細を飛ばしてマイページに戻ることはない。URLを直接開いた場合は、それぞれの応募一覧へ戻る。

通知書は遅延読み込み。応募IDと本人の役割で取得を絞り、既存の当事者RLSを使用する。本文は従来の契約記録から作り、凍結のない旧契約は求人記録から作成した旨を画面・PDF・印刷に残す。未確認の値は作らない。

読み込み失敗時は再読み込みと戻る操作を提供し、記録なしの場合と区別する。閲覧できない応募は本文・PDF操作を表示しない。DBへの書き込みは行わない。

`schedule-ui.test.mjs`で往復・進む・直接URL・両役割・対象ID・取得失敗と再試行を確認。`applicant-cards.test.mjs`で応募者一覧からの往復、`pdf-export.test.mjs`で印刷操作・PDFの全項目・複数ページ・タイムアウトと再試行を確認する。
